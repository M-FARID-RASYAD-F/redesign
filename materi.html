💡 Kenapa bootstrap/app.php Berbeda?

Di versi Laravel terbaru (Laravel 11 & 13), file tradisional seperti app/Http/Kernel.php sudah dihilangkan agar struktur proyek lebih ramping (lean).

Seluruh konfigurasi middleware kustom (seperti role dan active) didaftarkan langsung pada closure withMiddleware() di file bootstrap/app.php.

3. Fondasi Blade Templating: Dari Dasar Hingga Komponen

Memahami konsep pewarisan template (Inheritance), placeholder konten, partials, dan Blade components.

Konsep Template Inheritance memungkinkan kita membuat satu kerangka HTML induk (Master Layout), sehingga halaman-halaman anak tidak perlu menulis ulang tag <!DOCTYPE html>, <head>, CSS, maupun tag penutup </body>.

resources/views/layouts/app.blade.php (Master Layout) 
<!-- 1. Kerangka Dasar HTML Induk -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- @yield('title', default) menyediakan placeholder judul halaman -->
    <title>@yield('title', 'SMK Negeri 1 Nusantara - Official Website')</title>
    
    <link rel="stylesheet" href="{{ asset('css/style.css') }}">
    
    <!-- @stack('styles') menerima suntikan style CSS khusus halaman anak -->
    @stack('styles')
</head>
<body>
    @include('partials.navbar')

    <!-- Flash Message Global -->
    @if(session('success'))
        <div class="alert-success">✨ {{ session('success') }}</div>
    @endif

    <!-- @yield('konten_utama') adalah titik masuk konten dari halaman anak -->
    <main class="main-content">
        @yield('konten_utama')
    </main>

    @include('partials.footer')

    <!-- @stack('scripts') menerima suntikan skrip JS khusus halaman anak -->
    @stack('scripts')
</body>
</html>
resources/views/welcome.blade.php (Halaman Anak) 
<!-- Mewarisi kerangka dari layouts/app.blade.php -->
@extends('layouts.app')

<!-- Mengisi placeholder @yield('title') -->
@section('title', $sekolah['nama'] . ' - Portal Resmi Sekolah')

<!-- Mengisi placeholder @yield('konten_utama') -->
@section('konten_utama')
    <section class="hero">
        <h1>Selamat Datang di {{ $sekolah['nama'] }}</h1>
        <p>{{ $sekolah['slogan'] }}</p>
    </section>
@endsection
⚠️
Perbedaan Kritis: @yield ditulis pada Layout Master (Induk) sebagai penanda "lubang" konten, sedangkan @section ... @endsection ditulis pada View Anak untuk "mengisi lubang" tersebut.

Jika @extends digunakan untuk kerangka besar, @include digunakan untuk menyisipkan potongan HTML statis/modular yang berulang, seperti Navbar, Footer, atau Button WhatsApp.

🧩 Direktif @include

Menyisipkan file partial Blade tanpa perlu inheritance.

<!-- Memanggil resources/views/partials/navbar.blade.php -->
@include('partials.navbar')

<!-- Bisa juga mengirim parameter data tambahan -->
@include('partials.whatsapp-button', ['no' => '6281270001920'])
📚 Direktif @push dan @stack

Menumpuk JavaScript atau CSS spesifik satu halaman saja.

<!-- Di welcome.blade.php (anak) -->
@push('scripts')
    <script>
        console.log('Script ini hanya dimuat di halaman welcome!');
    </script>
@endpush

<!-- Di layouts/app.blade.php (induk) -->
@stack('scripts')

Keamanan form pada Laravel dijamin melalui token CSRF dan validasi interaktif menggunakan direktif @error dan old().

Contoh Form Kontak di resources/views/welcome.blade.php 
<form action="{{ route('kontak.submit') }}" method="POST" enctype="multipart/form-data">
    <!-- WAJIB: @csrf menghasilkan input hidden token keamanan untuk menangkal serangan Cross-Site Request Forgery -->
    @csrf

    <div class="form-group">
        <label for="nama">Nama Lengkap:</label>
        <!-- old('nama') menjaga input tidak terhapus jika validasi gagal -->
        <input type="text" name="nama" id="nama" value="{{ old('nama') }}" class="form-control">
        
        <!-- @error menampilkan pesan error validasi langsung di bawah field terkait -->
        @error('nama')
            <span class="error-text" style="color: #ef4444;">⚠️ {{ $message }}</span>
        @enderror
    </div>

    <button type="submit">Kirim Pesan</button>
</form>
✨
Pengondisian Status Autentikasi di Blade: Gunakan @auth ... @endauth untuk menampilkan menu khusus pengguna yang sudah login, dan @guest ... @endguest untuk menampilkan tombol Login/Register bagi pengunjung anonim.

Anonymous Blade Components adalah cara modern Laravel untuk membuat komponen UI independen dan reusable di folder resources/views/components/.

resources/views/components/stat-card.blade.php (File Komponen) 
@props([
    'label',
    'value',
    'icon' => '📊',
    'color' => '#eff6ff'
])

<div class="stat-card" style="background-color: {{ $color }};">
    <div class="stat-icon">{{ $icon }}</div>
    <div class="stat-content">
        <h4 class="stat-value">{{ $value }}</h4>
        <p class="stat-label">{{ $label }}</p>
    </div>

Cara Memanggil Komponen di View Lain 
<!-- Atribut statis tanpa titik dua (:) -->
<x-stat-card label="Guru & Staf" value="85 Pengajar" icon="👩‍🏫" />

<!-- Atribut dinamis menggunakan titik dua (:) agar dievaluasi sebagai PHP -->
<x-stat-card 
    :label="$st['label']" 
    :value="$st['value']" 
    :icon="$st['icon']" 
    :color="$st['color']" 
/>
💡
Aturan Emas: Jika mengirim nilai variabel PHP, wajib gunakan awalan titik dua (misal: :tabs="$cabang"). Jika hanya teks biasa, tidak perlu tanda titik dua (misal: tag="Prestasi").

4. Routing Terstruktur & Request Lifecycle

Mempelajari Named Routes, Prefix Grouping, Middleware Protection, dan pemisahan logika pada Controller.

Kutipan Arsitektur Rute di routes/web.php 
// 1. Rute Halaman Depan dengan Named Route
Route::get('/', [SchoolController::class, 'index'])->name('home');

// 2. Grup Rute Publik PPDB Mandiri (Prefix & Name Grouping)
Route::prefix('ppdb')->name('ppdb.')->group(function () {
    Route::get('/', [SchoolController::class, 'ppdbIndex'])->name('index');        // route('ppdb.index')
    Route::get('/daftar', [SchoolController::class, 'ppdbCreate'])->name('create');   // route('ppdb.create')
    Route::post('/daftar', [SchoolController::class, 'ppdbStore'])->name('store');    // route('ppdb.store')
    Route::get('/sukses/{no_pendaftaran}', [SchoolController::class, 'ppdbSuccess'])->name('success');
    Route::get('/cek-status', [SchoolController::class, 'ppdbTracking'])->name('tracking');
    Route::post('/cek-status', [SchoolController::class, 'ppdbCheckStatus'])->name('check');
});

// 3. Grup Rute Admin (Diproteksi Middleware Auth & RBAC)
Route::middleware('auth')->prefix('admin')->name('admin.')->group(function () {
    Route::get('/dashboard', [SuperAdminDashboardController::class, 'index'])->name('dashboard');
    
    // Hak Akses Khusus: Hanya Super Admin & Admin PPDB
    Route::middleware('role:super_admin,admin_ppdb')->group(function () {
        Route::get('/ppdb/export', [AdminController::class, 'ppdbExportCsv'])->name('ppdb.export');
        Route::post('/ppdb/{id}/status', [AdminController::class, 'ppdbUpdateStatus'])->name('ppdb.status');
    });
});

⚡ Optimalisasi Eloquent: Mengatasi Masalah N+1 Query
Best Practice Industri

Apa itu Masalah N+1? Jika kita memanggil relasi di dalam loop Blade tanpa Eager Loading, Laravel akan menjalankan 1 query untuk mengambil berita, lalu $N$ query tambahan untuk setiap baris berita hanya untuk mengambil nama kategorinya.

❌ Buruk (Tanpa Eager Loading): 
// Menjalankan 1 + 10 = 11 kali Query SQL ke MySQL!
$berita = News::latest()->take(10)->get();
@foreach($berita as $b)
    {{ $b->category->name }} <!-- Query dieksekusi berulang -->
@endforeach
✅ Bagus (Dengan Eager Loading with()): 
// Hanya mengeksekusi TEPAT 2 Query SQL ke MySQL!
$berita = News::with('category')->latest()->take(10)->get();
@foreach($berita as $b)
    {{ $b->category->name }} <!-- Sudah ada di memori RAM -->
@endforeach

6. Autentikasi & Multi-Role Access Control (RBAC)

Pemisahan 4 tingkat otoritas hak akses menggunakan Custom Middleware dan integrasi dual panel admin.

Role Akun Akses Landing Page & Modul Berita Akses Modul Guru & Jurusan Akses Modul PPDB Akses Pengguna Admin
super_admin Full CRUD Full CRUD Full CRUD + Export CSV Kelola User Penuh
admin_cms Full CRUD Full CRUD Read-Only Tidak Ada Akses
admin_ppdb Read-Only Read-Only Verifikasi & Export CSV Tidak Ada Akses
editor_akademik Read-Only Full CRUD Read-Only Tidak Ada Akses
app/Http/Middleware/CheckRole.php 
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class CheckRole
{
    public function handle(Request $request, Closure $next, string ...$roles): Response
    {
        $user = $request->user();

        // 1. Pastikan user telah login
        if (! $user) {
            return redirect()->route('login');
        }

        // 2. Validasi status keaktifan user
        if (! $user->is_active) {
            abort(403, 'Akun Anda dinonaktifkan. Silakan hubungi Administrator.');
        }

        // 3. Super admin selalu lolos, atau jika role cocok dengan daftar parameter
        if ($user->isSuperAdmin() || in_array($user->role, $roles)) {
            return $next($request);
        }

        abort(403, 'Akses ditolak: Anda tidak memiliki izin untuk mengakses modul ini.');
    }
}

7. Fitur Spesial: PPDB Mandiri & Streaming CSV Export

Penerimaan Peserta Didik Baru terintegrasi, cetak bukti registrasi digital, pelacakan status, dan unduh rekap data.

📜 Alur Pendaftaran PPDB Mandiri
  1. Calon siswa membuka portal informasi di /ppdb.
  2. Mengisi biodata diri dan orang tua di /ppdb/daftar.
  3. Mengunggah dokumen syarat (KK, Akta, Rapor, Foto) maks 3MB.
  4. Menyetujui persetujuan regulasi UU Perlindungan Data Pribadi (UU PDP No. 27/2022).
  5. Sistem menghasilkan kode registrasi unik: PPDB-YYYYMMDD-XXXX.
  6. Diarahkan ke /ppdb/sukses/{no} untuk melihat dan mencetak kartu bukti registrasi.
  7. Siswa dapat melacak status secara real-time di /ppdb/cek-status.
📊 Mengapa Menggunakan Streaming CSV?

Jika data pendaftar mencapai ribuan, membuat file Excel melalui pustaka biasa dapat menyebabkan server kehabisan memori (Memory Limit Exhausted).

Method ppdbExportCsv() di AdminController.php menggunakan response()->stream() untuk mengirim data baris demi baris secara langsung ke browser tanpa membebani RAM server, serta menyisipkan UTF-8 BOM (\xEF\xBB\xBF) agar file CSV langsung rapi saat dibuka di Microsoft Excel.

Kutipan Method ppdbExportCsv di app/Http/Controllers/AdminController.php 
public function ppdbExportCsv()
{
    $registrations = PpdbRegistration::orderBy('created_at', 'desc')->get();
    $filename = 'rekap-ppdb-' . date('Y-m-d_His') . '.csv';

    $headers = [
        'Content-Type'        => 'text/csv; charset=UTF-8',
        'Content-Disposition' => "attachment; filename=\"{$filename}\"",
    ];

    $callback = function () use ($registrations) {
        $file = fopen('php://output', 'w');
        
        // Menambahkan UTF-8 BOM untuk kompatibilitas Microsoft Excel (karakter tidak rusak)
        fprintf($file, chr(0xEF) . chr(0xBB) . chr(0xBF));

        // Header Kolom CSV
        fputcsv($file, ['No. Pendaftaran', 'Nama Lengkap', 'Jenis Kelamin', 'Status'], ';');

        // Tulis Baris Data
        foreach ($registrations as $reg) {
            fputcsv($file, [
                $reg->no_pendaftaran,
                $reg->full_name,
                $reg->gender == 'L' ? 'Laki-laki' : 'Perempuan',
                ucfirst($reg->status)
            ], ';');
        }
        fclose($file);
    };

    return response()->stream($callback, 200, $headers);
}
